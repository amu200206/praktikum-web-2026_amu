Project yang Pernah Dikerjakan

Berikut merupakan beberapa project yang saya kerjakan selama proses pembelajaran dan pengembangan kemampuan di bidang Teknik Informatika.

Project 1 - ElectroStock

Sistem Manajemen Inventori

ElectroStock merupakan sistem manajemen inventori yang dibuat untuk membantu proses pencatatan dan pengelolaan data barang serta persediaan.

Sistem ini dibuat untuk mempermudah pengguna dalam mengelola informasi barang sehingga proses pencatatan dapat dilakukan dengan lebih terstruktur.

Teknologi yang digunakan: HTML, CSS, PHP, dan MySQL.

Project 2 - Website Data Diri

Website Portofolio Mahasiswa

Website data diri merupakan website yang digunakan untuk menampilkan informasi mengenai profil, pendidikan, keahlian, pengalaman, dan project yang pernah dikerjakan.

Website ini juga menjadi media untuk memperkenalkan kemampuan dan pengalaman saya dalam bidang pengembangan website.

Teknologi yang digunakan: HTML dan CSS.

Project 3 - Aplikasi Absensi

Sistem Informasi Absensi Siswa

Aplikasi absensi merupakan project yang dikembangkan untuk membantu guru dalam melakukan proses pencatatan kehadiran siswa.

Sistem ini bertujuan untuk membuat proses absensi menjadi lebih terstruktur serta membantu pengguna dalam melihat dan mengelola data kehadiran siswa.

Project ini juga menjadi salah satu pengalaman dalam mempelajari pengembangan sistem informasi dan penerapan database.

Project 4 - Pengembangan Website Interaktif

Website Interaktif

Project ini berfokus pada pengembangan website yang memiliki tampilan dan interaksi yang dapat memberikan pengalaman yang lebih baik kepada pengguna.

Dalam proses pengembangannya, saya mempelajari struktur HTML, penggunaan CSS, serta konsep pemrograman untuk membuat halaman web yang lebih interaktif.

Teknologi yang digunakan: HTML, CSS, dan JavaScript.

Pengembangan Selanjutnya

Saya akan terus mengembangkan berbagai project di bidang teknologi informasi untuk meningkatkan kemampuan pemrograman, pengembangan sistem, database, dan kecerdasan buatan.

Setiap project menjadi bagian dari proses pembelajaran dan pengalaman untuk memahami bagaimana sebuah sistem dirancang, dikembangkan, dan digunakan untuk membantu menyelesaikan suatu permasalahan.
